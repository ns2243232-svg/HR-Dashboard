# HR Analytics Dashboard | Excel & Power BI

## Project Overview
This project analyzes HR data and presents workforce-related information through a Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- Microsoft Power BI

## Project Objectives
- Analyze employee data.
- Explore department-wise workforce distribution.
- Review salary and employee trends where data is available.
- Present HR metrics through visualizations.

## Files Included
- `HR Dashboard.pbix` — Power BI dashboard file.
- Dataset files — included if available.

## How to View
Download the `.pbix` file and open it using Microsoft Power BI Desktop.
